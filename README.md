# Hệ thống phân tích tội phạm TP.HCM

Demo web app React/Vite cho hệ thống quản lý vụ việc phạm tội.

## Chức năng

- Quản lý thông tin vụ việc
- Lọc tìm kiếm theo loại tội phạm, quận, trạng thái, thời gian
- Dashboard phân tích số vụ, loại tội phạm, xu hướng
- Hiển thị vụ việc trên bản đồ TP.HCM
- Xuất báo cáo PDF và Excel

## Chạy ứng dụng

1. Mở terminal tại thư mục `d:\dự án`
2. Chạy `npm install`
3. Chạy `npm run dev`
4. Truy cập `http://localhost:5173`
